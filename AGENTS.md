# Контекст проекта: Копия YouTube

Стек: Python 3.11, FastAPI, PostgreSQL, MinIO (S3), Redis, простой фронтенд (HTML/JS).

Требования:

- Роли: user, moderator, admin.

- Приватные видео видны только тем, кому разрешил владелец.

- Обязательный Swagger (/docs).

- Код должен быть чистым, с Type Hints и Docstrings.

- Мы используем Docker и docker-compose.
